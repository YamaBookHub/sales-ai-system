# データ保持・削除・委託先方針

## データ区分

| 区分 | 例 | 取扱い |
|---|---|---|
| アカウント | 氏名、メール、組織、権限 | 契約と認証に必要な期間だけ保持 |
| 営業データ | 会社、担当者、案件、メール、返信 | 顧客組織ごとに分離し、契約終了時の合意に従い出力・削除 |
| 監査・セキュリティ | 操作履歴、不可逆化IP識別子 | 不正防止、説明責任、法令上必要な期間だけ保持 |
| AI入出力 | 指示、案件要約、生成結果、使用量 | 機能提供と品質確認に必要な範囲だけ保持 |
| バックアップ | 暗号化DB dump | 日次35日、migration直前90日を標準とし、期限後に認証付きで削除 |

## 顧客からの請求

開示、訂正、利用停止、削除、契約終了時の出力は `LEGAL_CONTACT_EMAIL` の窓口で受け付ける。本人・管理者権限と対象組織を確認し、受付、判断、実施、通知を監査記録へ残す。

削除要求を受けた場合は、稼働DBの対象範囲、法令・紛争対応上の保持義務、バックアップからの自然消去期限を顧客へ説明する。バックアップを直接部分更新せず、復元時に削除要求を再適用する台帳を運用する。

## 外部委託先

実際に有効化したサービスだけを顧客向け一覧へ記載する。

| 種別 | 候補 | 目的 | 送信データ |
|---|---|---|---|
| ホスティング/DB | 採用するクラウド事業者 | API、DB、backup | 本サービス内データ |
| AI | OpenAI、Google | 分析、下書き、整合性確認 | 利用者が実行した案件情報・指示 |
| メール | Google Gmail API | 承認済みメール送信 | 宛先、件名、本文 |
| 認証 | Google OAuth/OIDC | 利用者認証 | メール、氏名、Google識別子 |

契約前に、所在地、再委託、保存、学習利用、削除、事故通知、安全管理措置を確認する。
