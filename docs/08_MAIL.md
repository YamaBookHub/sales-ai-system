# 08_MAIL

## メール設計

営業メールテンプレート、禁止表現、固定自己紹介、固定実績、文体ルールを管理します。

## CAMPFIRE営業メール定型文

件名:

```text
CAMPFIREでのプロジェクトを拝見しご連絡いたしました
```

本文:

```text
【企業名】 ご担当者様

突然のご連絡失礼いたします。
株式会社第弐ヴォヌールの山本と申します。

CAMPFIREで「【商品名／プロジェクト名】」を拝見しました。

【案件固有の魅力・特徴・強み】という点が特に印象に残っています。
【使う人】にとって、実際に使う場面をイメージしやすい商品だと感じました。

弊社では、クラウドファンディング支援とSNSマーケティング支援を行っています。

SNS運用では1か月総再生400万回超、クラウドファンディングでは担当案件で3,500万円規模の売上実績があります。

プロジェクトの魅力を伝える見せ方から、支援につながる導線づくりまでお手伝いしています。

もしご関心があれば、今回のプロジェクトに合わせた支援内容を簡単にお送りしますが、いかがでしょうか。
```

イベント、店舗改装、地域支援などの取り組み案件では、対象者の文だけ次に置き換える。

```text
【応援する人】にとって、参加・応援する理由が伝わりやすい取り組みだと感じました。
```

AIが埋める項目:

- 企業名
- 商品名またはプロジェクト名
- 案件種別（商品または取り組み）
- 案件固有の魅力・特徴・強み1つ
- 使う人または応援する人

担当者名が不明な場合は `企業名 ご担当者様` とする。本文では `様` を二重に付けない。

改行ルール:

- 1段落ごとに空行を1つだけ入れる。
- 1文の途中に空行を入れない。
- 読点 `、` の直後で段落を分けない。
- 長文でも意味のまとまりを優先し、テンプレート都合の細切れ改行は避ける。
- 指定された定型文にない過去商品分析、動画アイデア、強い提案、情報交換依頼を追加しない。

表現ルール:

- 初回接触のため `お世話になっております` は使わない。
- `素晴らしい`、`とても魅力的`、`親和性を感じた` など、どの案件にも当てはまる褒め言葉で個別性を代用しない。
- 達成率、残り日数、支援額、支援者数、価格、割引は案件の魅力として使わない。
- 最後は質問を1つだけ置き、相手が関心の有無を短く返信できる形にする。
- 担当者名、相手の課題、成果を推測または保証しない。
