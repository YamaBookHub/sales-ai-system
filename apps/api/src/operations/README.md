# Operations Module

`GET /api/reports/operations` は、ログイン中ユーザーの `organizationId` に限定した運用集計を返します。権限は `reports.read` と `ai.cost.read` の両方が必要です。

## 期間

- `from` と `to` は JST の暦日 (`YYYY-MM-DD`) で、両端を含みます。
- 省略時は、実行時点の JST を終点とする直近30暦日です。
- 最大期間は90暦日です。
- `period.asOf` は集計を作成したUTC時刻です。JST境界は `from 00:00:00 JST` から `to` の翌日 `00:00:00 JST` の直前までです。

## 集計の意味

- AI、返信、メール、完了済み検索、取り込みは、期間内に作成または完了監査された行を集計します。
- AI費用は、完了・失敗行では実費（未記録時は見積額）、予約中行では見積額です。
- 検索の `running` は、期間内に開始され、`asOf` 時点で実行中の検索ジョブです。完了・失敗・停止は安全な `projects.search_finished` 監査行から読みます。
- 取り込みは、直接取り込みの成功／失敗監査と、既存の一括取り込みサマリー監査を合算します。
- `stuck` 系のアラートは期間ではなく `asOf` 時点の未解消状態を数えます。`sending` が15分超、AI予約が30分超でアラートになります。

レスポンスには集計値と固定ラベルだけを含めます。メールアドレス、URL、会社名、本文、プロンプト、エラー内容、監査メモ、リクエストJSONは返しません。
